# Changelog

Cada sección `## [X.Y.Z]` se publica tal cual como "Novedades de esta versión" en la Microsoft Store
(máximo 1500 caracteres). El release falla si la versión de `package.json` no tiene sección aquí.

## [1.2.1] - 2026-11-25

- Organización, nombre común y unidad organizacional aceptan hasta 128 caracteres; la dirección, hasta 256.
- Los errores se muestran junto a cada campo y apenas se supera un límite.
- Al guardar la llave privada y el CSR puedes elegir la carpeta.
- El CSR solo se puede guardar después de la llave privada, para no perderla.
- Aviso al cerrar la aplicación si quedan archivos sin guardar.
- Nueva opción avanzada: generar la llave dentro de un token PKCS#11.
- El tamaño de la llave RSA pasa a las opciones avanzadas.
- La sección Acerca muestra la versión y la fecha correctas.
